# معمل العلوم الافتراضي

منصة تعليمية عربية باتجاه RTL لطلاب الصفوف الرابع والخامس والسادس في كلية التربية بجامعة الوادي الجديد. تضم المنصة تسع تجارب علمية تفاعلية بمشاهد ثلاثية الأبعاد.

## التشغيل المحلي

يتطلب المشروع Node.js وnpm.

```bash
npm install
npm run dev
```

افتح `http://localhost:3000` أثناء التطوير.

## التحقق والإنتاج

```bash
npm run lint
npm run build
npm run start
```

## بنية المشروع

- `src/app/` — صفحات App Router والمسارات.
- `components/experiments/` — مشاهد التجارب ومكوناتها التفاعلية ثلاثية الأبعاد.
- `components/ui/` و`components/layout/` — واجهة المنصة والتنقل والمحتوى المشترك.
- `data/` — بيانات التجارب والصفوف والمشروع.
- `public/` — الشعارات والأصول الثابتة.

لا تتطلب نسخة المشروع الحالية متغيرات بيئة. يمكن استيراد المستودع إلى Vercel واستخدام أوامر البناء الافتراضية `npm install` و`npm run build`.
